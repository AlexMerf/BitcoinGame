# Макеты дизайнера

Исходные макеты, по которым собрана современная версия игры. В production-сборку
они не попадают: единственное изображение из этой папки, которое использует
приложение, переехало в [`src/assets/game-field.png`](../src/assets/game-field.png)
(фон игрового поля).

## screens/

| Файл | Что это | Исходное имя |
| --- | --- | --- |
| `background-page.png` | фон страницы (сплошной цвет) | `BG.png` |
| `background-field.png` | фон игрового поля (сплошной цвет) | `Screen BG.png` |
| `game-screen.png` | макет игрового экрана | `Game 1.png` |
| `game-animation.gif` | анимированный макет игры | `Game 2.gif` |
| `win-screen.png` | макет экрана победы | `Win.png` |
| `reward-label.png` | надпись «Награда получена!» | `Награда получена_.png` |
