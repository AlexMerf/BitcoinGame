# Legacy: оригинальная страница 1998 года

Здесь сохранена оригинальная игра «Kill Leonardo Di Caprio Now!» 1998 года
(автор Andryxa, ishodniki.ru). Исходный архивный набор ассетов — кадры Леонардо,
которые в переделке стали вращающимися биткоинами.

## Как открыть

Откройте [`original-game.html`](original-game.html) двойным щелчком — страница
работает прямо из файловой системы, сервер не нужен. Картинки она берёт из
общей папки ассетов приложения (`src/assets/`), поэтому графика не дублируется:

- `src/assets/coin/frame-00.png … frame-17.png` — кадры анимации;
- `src/assets/game-field.png` — фон игрового поля.

Пути внутри страницы уже обновлены под новую структуру проекта.

## Файлы

| Файл | Что это |
| --- | --- |
| `original-game.html` | страница 1998 года; пути к общим картинкам обновлены под новую структуру |
| `js/main.js` | историческая копия скрипта (более ранняя «alpha»-версия); в ней остались исходные имена `l*.jpg` и `shotgun*.jpg`, к странице она не подключена |
| `css/main.css` | историческая копия стилей |
| `assets/l0f.jpg` | белый JPEG-плейсхолдер из исходного набора; нигде не используется |

Страница и эти файлы исключены из ESLint, Prettier и production-сборки: это
музейные экспонаты, а не рабочий код.
